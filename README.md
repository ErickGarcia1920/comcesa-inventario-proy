# COMCESA - Sistema de Consulta de Inventario y Precios

## Descripción

Estructura base del proyecto para una aplicación móvil de consulta de inventario y precios para la fuerza de ventas de la división automotriz de COMCESA.

## Arquitectura prevista

- Aplicación móvil.
- Backend en Node.js.
- Base de datos SQL Server.
- Integración con la información de Aspel SAE.

## Estructura del proyecto

```text
src/
  backend/
  mobile/
docs/
docker/
tests/
```

## Base de datos

La estructura contempla documentación y scripts relacionados con SQL Server y las tablas `INVE`, `MULT`, `PRECIOS01` y `PRECIO_X_PROD01`.
